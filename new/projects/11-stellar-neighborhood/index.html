01 / DISCOVER

First, define what is actually in the data.

The astronomical file is a historical RECONS-derived mirror, not a modern complete census. The media index is separately curated from linked source evidence. Neither source implies that fictional planets exist.

THE INTERPRETATION

Distance is real.
The destination is imagined.

A few nearby systems recur in this evidence index while most catalog IDs have no listed fiction connection. That pattern belongs to the curation, not to all science fiction. The complete source catalog and every media link can be audited and extended.
